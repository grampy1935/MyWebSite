# 音量の設定

設定されている音量を表示する音量スライドバーの先端をタップした状態で左右に移動させることにより、演奏時の音量を調整できます。

音量スライドバーの先端以外の部分をダブルタップすると、ミュートのオン／オフが切り替えられます。

楽器名をダブルタップするとサウンド設定ビューが表示され、イコライザーにより低音、中音、高音の音量を独立して調整することが可能です。
また、設定ビューにより「USBキーボード」を利用する設定をオンにしていると、同キーボードの音量調整が可能となります。
